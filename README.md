# ⏰ Pomodoro Timer 🍅
An app based on the Pomodoro technique to help you manage your time more efficiently, work smarter and avoid burnout. :muscle:

## Features:
 🛠️ Built with HTML, CSS and JavaScript.
 
 ⏰ Set of three modes (timers): 25 minutes timer for a Pomodoro session, 5 minutes timer 
 for a short break and 20 minutes timer for a long break.
   
 📱 Smooth, friendly, fully responsive and easy to understand UI that adapts to different screen sizes.
 
  🔘 Start, Reset and Stop buttons.
  
 💜 Beautiful gradient background of fucsia, purple and blue.

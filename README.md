# ⏰ Pomodoro Timer 🍅
An app based on the Pomodoro technique to help manage your time more efficiently, work smarter and improve your productivity while avoiding burnout. :muscle:

## Features:
 🛠️ Built with HTML, CSS and JavaScript.
 
 ⏰ Set of three modes (timers): 25 minute timer for a Pomodoro session, 5 minute timer 
 for a short break and 20 minute timer for a long break.
   
 📱 Smooth, friendly, fully responsive and easy to understand UI that adapts to different screen sizes.
 
  🔘 Start, Reset and Stop buttons.
  
 💜 Beautiful gradient background of hot pink, purple and blue.
